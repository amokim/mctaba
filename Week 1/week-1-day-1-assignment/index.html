I joined this course because I wanted to properly understand how websites are built, rather than just using tools that build them for me. I've dabbled with code before, but I felt it was time to sit down and learn the fundamentals of the web from the ground up, starting with the basics and working my way up to more advanced concepts.

By the end of this course, I hope to be able to build my own simple websites and small projects from scratch. My goal is to go from writing my very first line of HTML to putting together complete pages that look good, work well, and respond to what a user does.

Things I want to learn this month

  1. The basics of HTML and how to structure a web page properly
  2. How CSS works and how to style and lay out a page
  3. The fundamentals of JavaScript and how it brings pages to life
  4. How to put HTML, CSS, and JavaScript together to build a simple website
  5. How to make a web page interactive and respond to user actions
