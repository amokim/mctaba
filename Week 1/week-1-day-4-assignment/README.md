# Week 1 Day 4 Assignment

A single-page personal portfolio site for Amon Kimutai (AI Engineer & Software Developer, Nairobi, Kenya).

## Files

- **index.html** — Portfolio page with navbar (incl. hamburger menu and dark/light theme toggle), hero, about, animated skills bars, projects, and contact sections.
- **styles.css** — Styling for the page, including responsive layout and theme switching.

## Sections

- **Home** — Intro and calls to action (view projects / get in touch).
- **About** — Background summary and quick facts.
- **Skills** — Technical and soft skills with progress bars.
- **Projects** — Featured builds: ConversationManager, K8s Production Stack, StyleHub Nairobi.
- **Contact** — Email, GitHub, and LinkedIn links.

## Usage

Open `index.html` directly in a browser to view the page.
