# Week 1 Day 3 Assignment

HTML/CSS practice pages exploring layout, image galleries, and sticky navigation.

## Files

- **gallery.html** — "Kenya in Pictures" photo gallery grid with captions.
- **layout.html** — "TrackShamba" landing page layout with nav, hero, feature cards, and footer.
- **sticky-nav.html** — "Kenya Explorer" one-page site demonstrating a sticky/fixed navigation bar across multiple content sections.
- **styles.css** — Shared stylesheet for all three pages.

## Usage

Open any of the `.html` files directly in a browser to view the page.
